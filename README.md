# South America Methane — Grid Explorer

Interactive per-element explorer of an analytical Bayesian inversion of TROPOMI XCH₄ over South
America (2019–2025): emission and scale-factor maps, TROPOMI fit, sector totals, and trends. Three
independent toggles: **solver** (normal / lognormal / softplus), prior error **Sₐ** (diagonal 50% /
diagonal 100% / two-component continental + grid-cell), and observation error **Sₒ** (diagonal /
off-diagonal with a one-day temporal correlation). 18 configurations (3 × 3 × 2). Single
self-contained HTML page — no build step, no dependencies.

**Live:** enable GitHub Pages on this repo, then open `index.html`.
